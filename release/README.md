# Release staging

This directory contains drafts only. It does not authorize publication,
repository visibility changes, DOI deposition, or external notices.

The final release is gated on:

1. a clean PDF build and page-by-page visual preflight;
2. successful local and GitHub Actions verification;
3. human approval of authorship, AI disclosure, license, and qualified
   priority language;
4. human review of the public-safe repository surface; and
5. explicit approval of the public release and DOI metadata.

No private ChatGPT URL, local machine path, raw model transcript, or private
receipt belongs in a public release asset.

# Public-evidence boundary

The eventual public evidence subset must contain only theorem-level audit
reports, the exact verifier, deterministic logs, manifests, and checksum
ledgers needed to understand or replay the public claims.

It must exclude private conversation URLs, local absolute paths, account
identifiers, browser receipts, model-instance receipts, raw private chats, and
unrelated source material. Public audit summaries must distinguish symbolic
proof checking, exact computational corroboration, literature research, and
formal verification.

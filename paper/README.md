# Paper

The manuscript proves a negative answer to the literal all-positive generalized
coefficient inequality recorded in Hayman--Lingham Problem 5.44. It includes:

- the exact rational witness `(3/2, 1/14, 3, -1)`;
- the complete degree-three endpoint classification;
- rational positive-right-hand-side counterexamples at every index `j >= 3`.

The paper deliberately does not claim a counterexample to the classical
unit-square Brannan conjecture and does not claim absolute historical priority.

Build with:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error manuscript.tex
```

No author entry is included. Authorship and release metadata remain human
decisions before public release.

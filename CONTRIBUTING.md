# Contributing

Mathematical corrections are welcome. A useful report should identify the
exact theorem, equation, or inference and provide either a proof repair or a
literal counterexample.

Literature-priority corrections should cite a primary source, theorem/page,
exact hypotheses, and conclusion. Search snippets alone are not sufficient.

Changes to theorem scope, hypotheses, or load-bearing proof steps require a
new mathematical audit. Editorial changes require an exact source diff and a
clean PDF build and preflight check.

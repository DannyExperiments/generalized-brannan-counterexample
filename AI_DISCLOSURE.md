# AI assistance disclosure

This project used AI systems for mathematical discovery, proof development,
adversarial auditing, literature-search assistance, manuscript preparation,
formalization exploration, and repository assembly. Exact model-instance
receipts and private conversations are retained outside the public repository.

The repository identifies which claims are symbolic proofs, which are
exact computational checks, which have been independently reconstructed, and
which have or have not been kernel checked. AI assistance is not peer review,
historical-priority certification, or publication acceptance.

No AI system is listed as an author. The named author approved this disclosure
for the Version 1.0.0 public release.
